# 收货 SOP

本 SOP 供经理使用，目标是把收到的货物登记到共享表格 **“美国Logistar仓收件登记表-更新版9.02”**。收货登记和入库是两个独立过程，这里只讲收货登记。

## 1. 创建本次收货记录

在 WPF 打开“扫码录单”，点击 **“+ 创建新记录”**，建立本次记录，避免与之前的数据混在一起。

## 2. 扫运单、开箱、扫 SN

每个包裹按顺序操作：

1. 扫描箱子上的运单号。
2. 开箱。
3. 扫描设备 SN。
4. 系统识别到机型后，自动打印 label。
5. 无法识别机型时，在弹框中选择实际机型并确认；列表里没有时，可以输入新机型并使用。

这里弹框选择的是**机型**，不是共享表格里的“退件类型”。

WPF 会自动将记录写入 Excel，三列依次为“型号、SN、OID（运单号）”。

如果误选了机型，在复制前更正扫码 Excel 对应行的型号。当前 WPF 没有编辑已录记录的入口，重复扫描同一个 SN 不会改写原有 Excel 记录；只改 Excel 也不会改变已经打印的 label，错误的 label 需另行处理。

## 3. 打开 Excel，按运单号复制

扫码完成后，点击 WPF 的“打开扫描 Excel”按钮，打开本次记录。

按运单号选择对应记录，再复制到共享表格：

- **FedEx 运单** → “eBay&无源头退货登记表2025”页。
- **其他渠道运单** → “亚马逊收件登记表2025”页。

只复制数据行，不复制表头。列对应关系如下：

| 扫码 Excel | 共享表格 |
| --- | --- |
| A 列：型号 | B 列：机型 |
| B 列：SN | C 列：SN |
| C 列：OID | D 列：物流单号 |

保留 SN 和运单号的完整字符，按文本粘贴，避免长号码被截断或改变。

## 4. 确认登记完成

确认记录已粘贴到正确页面，型号、SN、运单号三列对应无误，且共享表格已保存。

经理只复制上述三列，**表格其他列由国内同事处理**，不覆盖或修改其他列。
