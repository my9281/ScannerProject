# ScannerProject 项目功能说明

更新日期：2026-09-08。本文以当前代码为准，区分 Windows 既有功能和 MAUI 迁移状态。

## 1. 产品与使用场景

幽梦运单之星扫描系统（YM-Star Scanner System）用于仓库扫码记录、工单匹配、标签打印、入库检测、出库核对和库位费比对。操作员使用键盘式扫码枪或键盘输入，通过 Enter 完成扫描。维护人员负责账号、文件模板、网络和标签机配置。

## 2. 组成与平台

| 项目 | 用途 | 当前状态 |
|---|---|---|
| Scanner | Windows WPF，.NET Framework 4.7.2 | 现有完整桌面业务基准 |
| Scan.MaUI | .NET 10 MAUI，Android、Windows、Mac Catalyst | 已接入业务，仍有迁移差异 |
| WmsUploadSite | 扫描日志上传配套站点 | 独立Web项目，部署见其README |
| tests | 条码分类和语言资源验证 | 不代表全部业务已验收 |

Intel Mac 目标为 maccatalyst-x64。Windows 上生成 MAUI DLL 仅证明代码编译，不证明原生应用打包、签名、启动和硬件打印成功。Android 保留单列滚动主页面，新增工具页需继续做窄屏实测。

## 3. 功能清单

### 登录与本地模式

支持账号登录、会话恢复、退出和无账号本地扫码。Windows 使用 DPAPI 保存会话及登录信息；MAUI 使用 SecureStorage。在线工单获取需要有效会话。本地模式跳过在线获取。

### 扫描、去重和OID

去除输入首尾空白，空输入不处理。单次运行按忽略大小写规则去重，记录时间和编号，并显示计数。重启会清空内存去重和OID次数。

OID包括34位数字、12位FedEx号码、1Z后16位字母数字，以及去除空白和 ]C1 前缀后以420开头且超过20位的编码。420开头且不超过20位的单独地区码会拦截。同一OID首扫不打印，从第二次开始按份数处理，每次播报OID。现有17个分类测试覆盖条码分类和OID首扫/重扫，不覆盖全部工单或打印行为。

### 工单与紧急规则

在线工单可按SN或运单号匹配，打印编号可转换为匹配工单SN。导入规则优先于在线数据。OID包含导入运单号时启动紧急上下文，后续非OID沿用，遇下一个OID清除或更换；多候选优先最长运单号。

Windows紧急文件支持XLSX及UTF-8 CSV：H=SN、K=故障描述、L=售后处理类型、O=退货运单号、S=工单状态。O规范化后长度必须大于4，S必须为待收件。备注合并去重，维修类型产生修字标记。MAUI的XLSX复用该导入器，但CSV仍使用旧J/Y/AD/AR列规则，不能声称两种格式均已对齐。

### 型号与标签

支持内置设备型号识别，打印时突出型号和末五位，标签包含完整SN、QR Code、Code128、日期和紧急备注。Windows支持手动选择及新增自定义型号、独立4×6/4×4排版、0/1/2份和用户设置保存。

MAUI已加入内置型号选择和纸张保存；自定义型号新增/持久化尚缺。Mac实现生成PDF并打开系统打印面板，当前每份会调用一次面板，未处理取消回报，不能视为静默连续打印。4×4目前缩放原布局，二维码比例和可扫性、长备注、修字、标签方向及打印边距均需完善或验证。

### 语音和日志

Windows使用System.Speech，MAUI使用系统TextToSpeech。两端有OID播报和中文尾五位播报，但无打印时播报、重复OID尾号等流程仍有差异。支持打开扫描日志、错误记录和上传。Windows日志位于用户Documents/SN Label Printer；MAUI位于应用数据目录logs。

### 入库检测

读取基础Excel和SN文本，输出匹配结果，包括类型、检测状态和处理日期；未匹配项标记不存在。可导出本月待检测CSV，按维修/非维修分类。处理日期固定减12小时后归月，这是现有业务规则，并非随夏令时自动转换。

Windows还提供当前月、上月、上两月、其余月份的分类数量、比例、总量和共享缓存。MAUI已提供导入、匹配及本月导出，尚未提供完整统计表和原缓存生命周期。

### 出库检测

将SKU/SN文本与入库基础数据匹配，形成类型、处理方式、时间等记录，汇总SKU数量并导出Excel。Windows提供明细表、托盘号和SKU汇总标签打印。MAUI目前提供汇总说明与Excel导出，未接入明细表及托盘打印。

### 库位费比对

选择库位费模板和入库基础Excel，逐工作表匹配并生成结果，显示工作表数、行数、匹配和未匹配数量。MAUI直接引用Windows处理服务，通过系统分享导出文件。移动端导入使用文件流复制到缓存，输出在缓存中，重要结果应及时另存。

### 多语言与界面

Windows登录、主页面及辅助窗口已有中文/英语/西班牙语资源，英文内嵌Bickham字体。MAUI登录和主页面继承三语言；新工具页、纸张文字和型号对话框仍有中文硬编码。主扫码页保持Android单列布局，新增页局部并排按钮仍需小屏验证。

## 4. 操作流程

1. 登录或进入本地模式，连接扫码枪，选择打印份数和纸张。
2. 在线模式刷新工单，需要时导入紧急文件；MAUI优先使用与Windows一致的XLSX模板。
3. 扫描SN或OID，检查状态、计数和打印结果；不识别型号时选择内置型号。
4. 从检测工具入口导入入库、出库或库位费文件，生成结果并保存/分享。
5. 遇到错误检查日志、网络及打印机。不要把系统打印面板关闭当作已打印确认。
