# 文档浏览与发布

## 使用入口

- Web：登录后，在“我的账户”点击“操作文档与 SOP”。
- Checklist：登录后，在工作台点击“操作文档”。

两端使用同一份服务端文档。需要 `checklist.read` 权限，现有 admin、user、viewer 均可阅读。未登录不能读取 Markdown、截图或附件。

## SOP 语言入口

文档总目录提供 [中文 SOP](sop/README.md)、[English SOPs](sop-en/README.md) 和 [SOP en español](sop-es/README.md)。Web 目录分别显示“仓库 SOP”“SOP (English)”和“SOP (Español)”分组；平板可通过每篇顶部的语言链接切换同一流程。

阅读说明见 [中文指引](sop/Language-Guide.md)、[English guide](sop-en/Language-Guide.md)、[Guía en español](sop-es/Language-Guide.md)。文档语言不改变应用按钮语言；截图及 Excel 共用中文目录资源，译文保留中文按钮名辅助定位。中文原文待梳理的流程，在所有语言中均保留待完善状态。在线版本使用 Markdown，现有收货 Word 文件不属于在线下载类型。

支持 Markdown 标题、列表、表格、代码块、PNG 截图和文档之间的链接。Web 可以下载 Excel，Checklist 下载后通过系统分享菜单保存或交给其他应用打开。

## 文档来源

内容来自仓库的 `docs/`，总功能说明来自根目录 `request.md`。构建、发布 Web 时，Markdown、PNG 和 Excel 自动复制到输出目录的 `Documentation/`。资源不放在公开的 `wwwroot` 中。

文档目录按仓库 SOP、系统资料、数据库资料和历史归档分类。原始 HTML 不执行；外部图片不加载。文档中指向工程源码或未发布文件的链接不提供文件访问。

## 发布步骤

1. 发布新版 Scanner.Web，并保留发布包中的 `Documentation/` 目录。
2. 更新 Checklist Android 应用，工作台才会出现“操作文档”入口。
3. 登录 Web 和平板，确认三语目录、每篇语言互链、阅读指引、收货/良品区/上架/返修 SOP、截图和 Excel 附件可访问；英文和西班牙语正文应分别带 `en`、`es` 语言标记。

更新 Markdown 或附件后，需要重新发布 Web 文档资源；平板使用“刷新目录”获取更新，不需要因文档内容变化重新安装应用。仅提交 Git 不会更新正在运行的服务。

## 接口

三个接口均要求登录账户的 Bearer token 和 `checklist.read` 权限，返回 `Cache-Control: no-store`：

| 接口 | 用途 |
| --- | --- |
| `GET /api/documents` | 文档目录 |
| `GET /api/documents/render?path=...` | 渲染后的文档，截图内嵌 |
| `GET /api/documents/file?path=...` | 下载 Markdown、PNG 或 Excel |

`path` 为文档目录下的相对路径。接口只接受实际发布的允许类型文件，不开放任意服务器路径，不跟随符号链接或目录联接。

## 验证

`dotnet run --project tests/Documentation.Tests/Documentation.Tests.csproj` 检查三种角色、匿名与失效会话、路径越界、HTML 与 URL 安全、实际文档渲染及附件内容。测试使用独立临时目录和测试账户，不访问生产数据库。
