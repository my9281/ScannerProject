# AndroidTester 标签打印

主界面第四项“打印标签”进入原生 MAUI 页面，在本页输入框扫码，收到回车即自动打印本次条码；也可点击“打印”提交输入框内容。进入页面自动聚焦，发送成功后清空并重新聚焦，状态文字提示发送结果。发送过程中暂停输入，避免重复回车触发重复任务。已内置用户提供的容大 Android SDK，通过经典蓝牙 EDR 直接连接 RP425。

首次使用：在安卓系统蓝牙设置里配对打印机，扫描条码后点击“打印”，允许附近设备权限，选择打印机并按自测页选择 TSPL（国内版）或 ZPL（国际版）。之后记住选择，每次打印重新连接。长按“打印”按钮可清除选择、更换设备或指令类型。若蓝牙没有任何已配对设备，应用提供打开系统蓝牙设置的入口。

打印内容为本页输入框中的非空扫码，同时更新最近扫码记录，不再使用其他页面的历史扫码作为打印输入。取消或失败保留输入，检查出纸后可回车重试。没有扫码内容时提示先扫描，不生成空标签。

标签移植自 WPF `PrintingHelper.CreateWideLabel` 的普通 4×6 横向模板：SN 全文、末五位、二维码、Code 128 条码、打印日期。二维码和条码均编码完整扫描值，保留前导零。当前 Tester 没有工单或机型输入，不生成紧急、维修或机型字段。

使用约 4×6 英寸标签纸，SDK 纸张设置为 102×152 mm，TSPL 间隙为 3 mm；模板旋转为 816×1216 点位图，适配约 203 dpi、4 英寸纸宽。不同耗材间隙需要在代码中调整。

容大 SDK 负责生成 TSPL/ZPL 位图指令、建立蓝牙连接和发送。连接超时 25 秒、发送确认超时 60 秒；不自动重试打印。回调仅确认数据发送，不代表纸张已经打印。失败或超时后先检查出纸再重试，避免重复打印。真实打印及扫码识别需使用目标打印机验证。

界面和 Android 提示音均为原生实现，不依赖旧版 WebView 的 JavaScript 能力。
