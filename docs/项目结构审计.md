# 项目结构与命名空间审计

审计日期：2026-09-12。范围为 Scanner.slnx 中全部8个项目的 C# 源文件，不包含 bin、obj、第三方包和 IDE 缓存。

| 项目/目录 | 命名空间及职责 |
|---|---|
| Scanner.WPF | WPF应用、窗口、平台服务；子目录使用 Scanner.WPF.Helpers / Services / Controllers / ViewModels / Properties |
| Scan.MaUI | MAUI应用与页面；子目录使用 Scan.MaUI.Services / Controllers / Views / Windows / ViewModels / Converters |
| Scanner.Models | 共享业务模型 |
| Scanner.Models/MauiContracts | Scanner.Models.MauiContracts，MAUI使用的数据传输模型 |
| Scanner.Helpers/Services | Scanner.Helpers.Services，共享文件解析、检测、比对和导出 |
| Scanner.Controllers | 控制器基础契约和工厂接口 |
| Scanner.ViewModels | 共享属性通知与ViewModel契约 |
| Scanner.DI | 共享服务注册及生命周期 |
| WmsUploadSite | 独立Web入口，Program.cs采用顶级语句 |
| SharedAssets | 共用语言字典与字体，两端分别按平台资源类型编译，不属于任何UI工程 |

共享项目通过 ProjectReference 引用，解决方案内应用不跨目录 Compile 引入另一工程的类文件。测试中为隔离平台依赖而显式编译生产源文件属于测试夹具用途。

MAUI Platforms 下的启动类保留框架模板约定：Android/iOS/Mac Catalyst采用应用根命名空间，Windows采用 Scan.MaUI.WinUI。AssemblyInfo.cs为程序集属性，不声明业务类命名空间。这些属于明确例外。

运行 tests/AuditProjectLayout.ps1 可检查项目引用是否存在、全部源文件命名空间是否对应目录，以及是否存在跨工程源码编译。一个文件中的辅助类型若与该文件主类型职责相关，可保留同一文件；本次不因文件内有多个类型而拆散平台实现。

旧 Scanner / MaUIScanner 路径如仍存在，只保留受占用的本地构建缓存、包或IDE文件，不再是解决方案工程。历史Excel进度表保留原工程名作为历史记录。

工程及程序集更名可能使WPF按程序集标识保存的用户设置位置变化。未修改MAUI ApplicationId，未迁移或删除用户会话、日志和配置数据。
