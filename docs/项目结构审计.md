# 工程总览与结构说明

核对日期：2026-10-21。以 Scanner.slnx、工程配置及当前源码为依据：解决方案包含 **17 个工程**，测试工程另在 tests/。代码实现不等于生产部署或设备验收完成。

## 应用工程（7 个）

| 工程 | 职责与使用对象 | 平台及边界 | 详细资料 |
| --- | --- | --- | --- |
| Scanner.WPF | 仓库 Windows 主工作台：基础表、工单、扫码打印、匹配、良品上架、日报月报 | .NET 10 WPF；依赖本机打印机、基础表与服务器 | [功能目录](../request.md)、[发布更新](WPF发布与自动更新.md) |
| Scanner.MaUI | 原 Mac 迁移客户端：登录、扫码、导入导出、匹配、上架上传及费用计算 | .NET 10 MAUI；声明 Android/iOS/Mac Catalyst/Windows；Mac 打印走 PDF 及系统对话框，平台需分别验收 | [实现范围](../request.md) |
| Scanner.AndroidTester | PDA 良品区 SN、库位、SKU/SN 批次及蓝牙打印 | .NET 10 MAUI，主要 Android；SKU/SN 批次持久化，良品区和库位待上传队列仅内存 | [PDA 说明](../Scanner.AndroidTester/README.md) |
| Scanner.CheckListBoard | 检测平板登录、权限、真实工单读写、操作文档 | .NET 10 MAUI，主要 Android；检测、评级等模块仍待接入 | [平板说明](../Scanner.CheckListBoard/README.md) |
| BreezaryStar/ScannerProject.BreezaryStar.WPF | 收货数据读取测试应用；管理员登录后读取服务器预报数据，只读动态列展示 | .NET 10 WPF；腾讯 OAuth 和数据库访问留在服务器 | [Breezary WPF](../BreezaryStar/README.md) |
| BreezaryStar/Scanner.BreezaryStar.CheckBoard | 在原平板基础上增加预报查询、搜索及刷新 | .NET 10 MAUI；独立应用标识与设置；预报接口当前要求管理员 | [Breezary 平板](../BreezaryStar/Scanner.BreezaryStar.CheckBoard/README.md) |
| BreezaryStar/Scanner.BreezaryStar.AndroidScanner | 扫码入库：原始条码、位置、设备及时间持久化，分批上传 | .NET 10 Android；独立应用；不做 SKU/SN 分类，不自动回写腾讯预报 | [扫码入库](../BreezaryStar/Scanner.BreezaryStar.AndroidScanner/README.md) |

## 服务端工程（4 个）

| 工程 | 职责与边界 | 目标与引用 |
| --- | --- | --- |
| Scanner.Web | ASP.NET Core API 与网页；认证权限、工单、文档、托盘、腾讯同步、Breezary 入库和 WPF 更新；部分业务仍在其 Services 内 | net10.0；引用 BLL、DAL、Model；[服务端入口](../Scanner.Web/README.md) |
| Scanner.Server.BLL | 订单、数据库健康、良品区、库位、上架服务及 SKU/SN 校验，调用仓储 | net10.0；引用 DAL、Model |
| Scanner.Server.DAL | MySQL 连接工厂、仓储与事务；上架写入、工单审核和良品区归档联动 | net10.0；引用 Model，使用 MySqlConnector |
| Scanner.Server.Model | 服务端订单、托盘、库位、批次、配置及请求/响应模型 | net10.0；与客户端 Models 分属不同契约 |

数据库以 [数据库目录](database/README.md) 为入口，仓库脚本、现场快照及实际部署结果需分别核实。

## 共享与平台支持工程（6 个）

| 工程 | 职责 | 目标与边界 |
| --- | --- | --- |
| Scanner.Models | 客户端业务模型及 MauiContracts 数据传输契约 | netstandard2.0；不承载平台 UI |
| Scanner.Helpers | Excel/文本解析、检测匹配、导出、紧急工单和基础表缓存 | net472 / net10.0；引用 Models |
| Scanner.DI | 共享服务注册、ScannerDependencies 及应用级 ChecklistDataCache 生命周期 | net472 / net10.0；引用 Helpers；正式名称为 DI |
| Scanner.Controllers | IController、IControllerFactory、ControllerBase 基础契约 | netstandard2.0；不是 Web API 控制器工程 |
| Scanner.ViewModels | 属性通知基类与 ViewModel 契约 | netstandard2.0；具体页面逻辑仍在客户端 |
| Scanner.Rongta.Android | 容大 Android 打印 SDK 绑定，供 AndroidTester 使用 | net10.0-android；[SDK 说明](../Scanner.Rongta.Android/README.md) |

引用方向：WPF / MaUI → DI、Helpers、Models、Controllers、ViewModels；DI → Helpers → Models；AndroidTester 的 Android 目标 → Rongta。共享库保留 net472 不代表 WPF 主程序仍使用 .NET Framework。见 [共享工程](shared-projects.md)。

## 维护与核验

增减工程时同步更新本表、根 README 与专项文档。tests/AuditProjectLayout.ps1 可辅助检查引用、命名空间及跨工程源码编译，不代替构建、设备验收或部署检查。MAUI 启动模板及程序集属性允许框架约定例外。
