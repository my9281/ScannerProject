# 收货 SOP

本 SOP 供经理使用，目标是把收到的货物登记到共享表格 **“美国Logistar仓收件登记表-更新版9.02”**。收货登记和入库是两个独立过程，这里只讲收货登记。

## 1. 导出预报和工单

执行收货登记的全部操作前，先从 BLUETTI after-sales 系统导出预报和工单，准备好本次收货需要的资料。

## 2. 标记当天日期，创建收货记录

每天开始收货时，在共享表格当天记录的起始位置 **A 列标记日期**。

在 WPF 打开“扫码录单”，点击 **“+ 创建新记录”**，建立本次记录，避免与之前的数据混在一起。

**开始扫描前，先新建本次收货的 TXT 和 Excel 记录文件，再扫描运单号。**

## 3. 扫运单、开箱、扫 SN

### 整托货物的运单确认

整托收货的情况较少，以下作为整托货物送达时的补充流程。整托可能只有一张签收单和一份运单，运单订在其中一件货物上。先找到这份运单，确认整托对应的物流单号；不要因其他箱子没有单独运单而漏记整托单号。

例如本次整托货物的运单号为 **439752659**（ArcBest，标签上也写作“439 752 659”）。在本次 TXT 和 Excel 文件创建完成后，先扫描这个运单号，再继续开箱和扫描设备 SN。

### 拆托与包装清理

扫描整托运单号后，拆托，保留签收单、运单等纸质单据。拆下的缠绕膜及时扔进垃圾桶；缠绕膜很占地方，不要堆放在收货作业区域。

### 扫码顺序

整托货物先按上述步骤扫描整托运单号、拆托，再依次处理每一台机器。单独送达的包裹先扫描箱子上的运单号，然后按以下顺序操作：

1. 拆开机器的包装箱。
2. 取出机器。
3. 扫描机器上的 SN。
4. 系统识别到机型后，自动打印 label。
5. 无法识别机型时，在弹框中选择实际机型并确认；列表里没有时，可以输入新机型并使用。
6. 每台机器扫描并打印 label 后，将对应的 label **一张放进盒子里，一张贴在盒子外面**，确认标签与该机器对应。

这里弹框选择的是**机型**，不是共享表格里的“退件类型”。

WPF 会自动将记录写入 Excel，三列依次为“型号、SN、OID（运单号）”。

收货时还有两项需要单独记录到共享表格 **A 列**：

- **EL10、EL100、EB3A** 有不同颜色，在对应记录的 A 列注明实际颜色。
- **线材**需要拍照，将照片上传到对应记录的 A 列。

如果误选了机型，在复制前更正扫码 Excel 对应行的型号。当前 WPF 没有编辑已录记录的入口，重复扫描同一个 SN 不会改写原有 Excel 记录；只改 Excel 也不会改变已经打印的 label，错误的 label 需另行处理。

## 4. 导出 Excel，按运单号复制

依次完成本次所有机器的 SN 扫描后，导出本次收货 Excel。WPF 会自动写入扫码 Excel，点击“打开扫描 Excel”按钮即可打开本次记录。

按运单号选择对应记录，再复制到共享表格：

- **FedEx 运单** → “eBay&无源头退货登记表2025”页。
- **其他渠道运单** → “亚马逊收件登记表2025”页。

只复制数据行，不复制表头。列对应关系如下：

| 扫码 Excel | 共享表格 |
| --- | --- |
| A 列：型号 | B 列：机型 |
| B 列：SN | C 列：SN |
| C 列：OID | D 列：物流单号 |

保留 SN 和运单号的完整字符，按文本粘贴，避免长号码被截断或改变。

## 5. 确认登记完成

确认记录已粘贴到正确页面，型号、SN、运单号三列对应无误，且共享表格已保存。

经理将扫码 Excel 的三列复制到共享表格 B—D 列，并在 A 列标记当天日期、指定机型的颜色和线材照片。**其余列由国内同事处理**，复制时不要覆盖 A 列已填写的内容或国内同事维护的列。

## 6. 推至待修区域

本次收货扫码、Excel 导出和登记完成后，将机器推到待修区域。
