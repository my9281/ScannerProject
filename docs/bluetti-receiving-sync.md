# BLUETTI Web 预报定时同步：运行说明

实现日期：2026-11-15。对应 [收货监控总体方案](carrier-receiving.md) 的客户预报池与已知运单自动查询部分。

## 已实现

- 将 WPF `BluettiSessionService`、`BluettiApiExporter` 的登录和导出协议迁入 Web，不依赖 WPF、浏览器或桌面会话文件。
- 每次客户同步重新登录：密码 SHA-256、大写十六进制，读取用户信息，核验可用站点，校验站点权限，再导出客户预报 XLSX。令牌只在该次请求流程的内存中使用。
- 使用与 WPF 相同的 `exportCustomerDemands` 接口和 `type=1/state=1` 过滤条件。当前为周期性完整导出，不是按更新时间增量拉取；真实联调需确认导出是否完整、过滤范围是否符合收货业务。
- 解析表头“退货物流商”“退货运单号”及 RMA，支持 FedEx 与 USPS；缺失运单和不支持的承运商保留为资料问题，不丢弃整行。
- 同一 RMA、承运商和运单的多商品行合并为一条关联，保留原始行集合；不同 RMA 可以关联相同包裹。没有 RMA 时按行内容生成稳定标识。
- 成功导出作为当前客户预报快照，保留历史记录。有效运单幂等加入已有 `carrier_receiving` 跟踪清单，不覆盖已有实收信息；未出现在新快照中的包裹不会自动删除或认定取消。
- Web 托管后台任务每 15 秒检查各域数据库配置，按到期时间执行。下一次客户同步从本次完成/失败后按配置周期计算。
- MySQL 连接级命名锁防止同一数据库、同一域并发导出；导入与成功状态在事务中提交，并校验配置版本。配置在同步中变化时，旧任务结果回滚。
- 同步失败保留上次成功快照，记录错误并等待下一周期；中断的运行在下次重试时标记为 interrupted。停止服务时响应取消，重启后读取数据库进度。
- 可启用已知运单自动查询：每批最多 20 个已登记且未实收包裹，按上次尝试时间公平排序；失败不清除成功状态，并对对应承运商按查询周期冷却。

## 配置与入口

管理员登录后打开“BLUETTI 预报自动同步”，地址 `/receiving-sync.html`。填写用户名、密码、站点 ID、客户同步周期和自动查询开关/周期。

密码加密存数据库，不回传明文；留空保留原密码，更换用户名需提供新密码或清除旧密码。配置保存有版本校验，后台后续任务直接读取新配置，不需要 XML 或重启。

客户周期允许 300–86400 秒，默认 1800 秒；单个运单查询周期允许 60–86400 秒，默认 1800 秒。定时检查周期为 15 秒，一个实例依次处理各域，长任务会影响后续任务开始时间，不能保证精确到秒。

“立即请求同步”只将任务设为到期，由后台执行，页面不会等待长时间导出。页面展示最近尝试、最近成功、下一到期、最近错误、关联记录数量与资料问题数量，并每 15 秒更新；不会自动覆盖管理员正在编辑的表单。

自动物流查询还要求在 `/carrier-receiving.html` 分别配置并启用承运商。此处只按已知运单查询，没有实现承运商独立来件发现。

## 数据库与部署

先执行 `Scanner.Web/Database/022_carrier_receiving.sql`，再执行 `023_bluetti_receiving_sync.sql`。023 已改为检查字段/索引后添加，可以重试；接入 PDA 还需 024。也可一次执行 `receiving_pending_all.sql` 合并版。没有对现有数据库自动执行这些脚本。

023 新建客户同步配置、预报快照记录、同步运行日志表，并为已有包裹增加查询尝试/错误字段，为承运商配置增加失败冷却字段。运行日志在 `receiving_sync_runs`；页面目前展示最新结果，尚无完整日志查询页面。

确保 Web 进程持续运行：后台任务只在 Web 进程存活期间调度。IIS 部署需配置持续运行/预加载与适当的空闲回收策略；仅保持浏览器页面打开不能保证后台持续运行。

沿用 `App_Data/carrier-keys` 的 Data Protection 密钥，发布、备份与多实例部署必须保留/共享，并限制文件访问权限。当前每个账户域配置一个 BLUETTI 站点；多客户、多仓库连接管理尚未实现。

切换站点会清空当前快照指针与对应计数，成功导出后再展示新站点快照；历史行和原有跟踪包裹保留。自动跟踪清单目前仍按域处理，切换站点不会自动停止旧包裹的跟踪。

## 接口

所有接口均需账户 Bearer 会话和 `system.configure` 权限：

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/receiving-sync/settings` | 配置与最后运行结果，不返回密码 |
| `PUT /api/receiving-sync/settings` | 更新配置及版本，设为到期 |
| `POST /api/receiving-sync/run` | 请求下一次后台检查时同步，返回 202 |
| `GET /api/receiving-sync/forecasts?before=0` | 最近成功快照，每页最多 100 条 |
