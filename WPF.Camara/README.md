## 操作

1. 打开“按卡板打印4×6”，选择卡板。
2. 选择“逐件打印”（按预报数量每件一张），或“作业单”（每行一张、注明该行数量）。
3. 点选行检查预览。可修改当前行打印份数，再点“打印当前行4×6标签”；也可点“打印所选整板4×6标签”。整板按预报数量或每行一张规则生成，不使用当前行临时份数。
4. 在程序内选择支持ZPL的标签打印机（如ZPL RP425 Rongta），选择与机器一致的203或300 DPI。点击后逐张直接发送ZPL指令，不弹出系统打印窗口。4×6尺寸由指令指定。默认不会在打开或选择卡板时打印。

标签包含：卡板号、源表行号、预报数量、逐件序号、完整SKU、校对码Code128一维条码、SKU二维码、已有截图支持的配置、原始码及核对/签名栏。内存卡信息省略。

一维条码使用预报第4列校对码，二维码使用第5列完整SKU，两者内容不同。原始码与校对码不同会明确提示。LPN条码按新表第4列保留，不自动推测或替换为其他商品码。预报行不合并，保持每行数量及来源可追溯。

配置只取自用户提供的型号截图：S8951系列、S840系列、F5100/F5800系列、S850/S860系列。未提供截图的型号（包括S8981、S5517等）标记“配置待补充资料”，不会套用相似型号的功能。5C/7C电缆规格以具体SKU为准；不改变字母大小写或后缀顺序。

“导入其他预报”支持UTF-8制表符分隔的.txt/.tsv，5列或7列，前5列为：卡板、原始码、数量、校对码、SKU。卡板空白行向下承接。导入失败保留原数据；导入内容仅本次运行有效。重新打开恢复内置预报。

卡板名称也支持“散货1”等正整数编号的散货分组，内部以负数ID与原卡板分开。内置合并后的散货源行号为141–157。

旧的“本次打印清单”和“型号与规格”功能仍可使用，打印旧式SKU二维码标签。

## 逐张直接发送

所有三个页面都改用ZPL RAW发送，每张一个独立打印任务、份数固定1，任务按顺序提交。中文及标签内容转为黑白位图，不依赖打印机内置中文字库。按卡板模式固定4×6英寸，旧页面按设置的毫米尺寸。程序优先选中名称包含Rongta/ZPL的已安装打印机，可刷新并手动选择；203 DPI是默认值。只适用于支持ZPL的打印机。

进度表示已提交给打印队列的数量，不代表已经物理出纸。停止按钮只停止后续标签发送；已进入Windows队列或机器缓存的任务可能继续出纸。失败时停止后续发送并报告成功提交张数，不会自动重试导致重打；失败的当前张请核对队列和出纸后再补打。传输仍经过Windows打印队列，绕过的是系统打印对话框和文档渲染驱动。

新增验证：203/300 DPI的ZPL单张指令、栅格数据长度以及一维条码/二维码从实际发送位图的解码，顺序发送、停止及失败后不继续不重试。未实际发送测试标签。


## 打印截断修复

整页4×6位图在203 DPI为124236字节、300 DPI为270000字节，超过单个ZPL ^GF字段99999字节限制。现按行拆分为最多4096字节的独立图像块，逐块指定纵向位置，所有块仍位于同一个^XA/^XZ格式内，一张纸一个打印任务。传输也改为每次最多4096字节，遇到短写只续写尚未接收的字节；零写入或异常立即停止。回归测试覆盖203/300 DPI分块限额、全页连续覆盖、拼接后与原图逐像素一致及条码解码，包含此次第14板第109行。


## 开始维修录入

主窗口右上角“开始维修录入”打开 SN/SKU 配对窗口，各 1–50 位；记录首个编码录入时间，人工确认后上传到现有 `repair_scan_records` 表，状态为“开始维修”。支持分别清除、失败保留与重启恢复重试。配置及部署见 [开始维修录入说明](../docs/camara-repair-start.md)。不包含运单收货或 Web 看板。
## 标签数据文件与导出

默认核对明细、批量贴标清单及型号规格已统一保存在 [Data/label-data.json](Data/label-data.json)，程序从内嵌 JSON 加载。主窗口“导出标签数据”可保存当前全部核对明细和已修改的清单数量。原 TSV 来源保留，导出不会覆盖默认数据；Excel 导入待提供实际表格后规划。字段与使用说明见 [标签数据序列化](../docs/camara-label-data.md)。
