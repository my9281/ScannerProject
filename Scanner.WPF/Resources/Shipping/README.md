# 发货 SKU 参考资源

`SkuCatalog-2026-11-03.xlsx` 为用户提供的 `SKU数据清单-2026_11_3(1).xlsx` 原件副本，内嵌到桌面程序，离线可用。工作表“单品SKU ”共有 11,983 条数据。

桌面程序 → OMS 发货 → 查询 SKU 尺寸 / 类型 / 描述。输入 SKU、型号或描述中的部分文字可查询；忽略大小写、兼容全角字符，空格分隔多个关键词时需全部匹配。选择结果可复制查看全部原始字段。表内无独立备注列，因此搜索覆盖全部字段，包括库存 SKU 描述、物料名称、产品规格和类型等文字。

列表的长宽高来自“长(CM) / 宽(CM) / 高(CM)”，重量来自“重量(KG)”，与裸机尺寸分开展示。缺失数值保持为空。OMS 表单使用 INCH/LB，查询结果仅供核对，不自动填入表单；发货前应核对实际包装并换算单位。

更换资源时应保持列结构，更新版本文字及行数验证，再重新构建。
