# 发货 SKU 参考资源

`SkuCatalog-2026-11-03.xlsx` 为用户提供的 `SKU数据清单-2026_11_3(1).xlsx` 原件副本，内嵌到桌面程序，离线可用。工作表“单品SKU ”共有 11,983 条数据。

桌面程序 → OMS 发货 → 查询并应用 SKU 尺寸 / 重量。输入 SKU、型号或描述中的部分文字可查询。查询忽略大小写、兼容全角字符，空格分隔多个关键词时需全部匹配。选择结果可查看全部原始字段。

列表将包装长宽高（CM）和重量（KG）换算成 IN / LB 并分别向上取整。选择一条有包装数值的记录，点击“应用到出库面单”可填入四项。原表缺失或无效的值会清空对应表单字段，避免混用不同 SKU 的数值，之后可手动补填。

更换资源时应保持列结构，更新版本文字及行数验证，再重新构建。
