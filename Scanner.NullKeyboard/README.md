# 空白输入法

独立的 Android 原生输入法，用于 PDA 扫码时使用紧凑单行数字软键盘。最低 Android 7.0（API 24），与 Scanner.AndroidTester PDA 项目一致；纯 Java，无 CPU 架构限制，无第三方库、无联网或其他 uses-permission。

APK：`../output/NullKeyboard/NullKeyboard-1.1.apk`。

安装后打开“空白输入法”，先进入系统输入法设置启用，再点击选择输入法切换。要恢复打字，重新打开此应用切回原输入法。系统可能显示所有第三方输入法通用的启用提示。

1.1 版只显示一行 1–0 数字按键，高度固定 36dp，无内外边距及候选栏，不进入横屏全屏编辑模式。数字点击通过 InputConnection 提交，不拦截或改写硬件按键。系统导航栏由设备系统管理，可能另占高度。扫码枪的具体输出方式和设备系统适配仍需在目标 PDA 实测。

构建：在仓库根目录运行 `./Scanner.NullKeyboard/build.ps1`。脚本使用本机 Android SDK 36 和 JDK 21，生成并验证签名 APK。`signing/` 保存本地分发签名密钥，已忽略版本控制；后续覆盖升级应保留此密钥。构建脚本中的密码用于本地签名文件保护，不是服务凭据。
