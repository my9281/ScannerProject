# Breezary 预报表格说明

这个表格用来提前登记寄回维修的包裹信息，方便大家查看预报和后续签收情况。

## 谁可以查看和编辑

所有人都可以浏览表格，编辑仅限客服人员和维修管理人员。

## 客服需要填写什么

客服登记预报时，需要填写以下六项：

| 字段 | 填写内容 |
| --- | --- |
| 工单号 | 这次维修对应的工单号。 |
| 渠道 | 包裹使用的快递渠道，例如 UPS。 |
| 运单号 | 寄出包裹的快递单号。 |
| SKU | 寄回产品的 SKU。 |
| 发货日期 | 包裹实际寄出的日期。 |
| 问题描述 | 产品有什么问题、为什么寄回维修，尽量写清楚，方便维修人员了解情况。 |

## 哪些信息由系统核对

紧接在“问题描述”后面的五项，由系统核对并更新显示：

| 字段 | 说明 |
| --- | --- |
| 是否签收 | 核对包裹是否已经签收。 |
| 实际签收快递单号 | 核对实际收到包裹的快递单号。 |
| 签收日期 | 核对包裹实际签收的日期。 |
| 状态流转 | 显示对应的业务处理状态。 |
| 备注 | 显示对应的补充说明。 |

这五项不属于客服登记预报时需要填写的内容。

## 表格什么时候更新

后台系统每天会按以下两个时间同步数据：

- **新泽西当地时间每天早上 8 点**：自动拉取表格中更新的预报信息。
- **北京时间每天早上 8 点**：将当天收货数据同步，并与表格中的预报记录进行匹配，在对应记录中显示核对结果。

客服填写预报后，后台会按上述时间更新数据；收货后的核对信息也会在同步、匹配后显示到表格中。

## 入库检查时怎么查看

预报信息和收货信息会提供到入库检查系统中，方便检查人员了解寄回产品的情况，并核对收货信息。

在入库检查系统中打开“查看预报”，可以查看工单号、SKU、快递单号、问题描述，以及签收情况、状态流转和备注等信息。也可以通过搜索工单号、SKU、运单号等内容，找到对应记录。

需要查看更新后的信息时，点击“刷新预报”。页面显示的是后台已经同步的数据，最新预报和收货信息会在后台完成同步后提供查看。
